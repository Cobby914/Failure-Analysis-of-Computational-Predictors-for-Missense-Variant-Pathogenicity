# Failure-Analysis-of-Computational-Predictors-for-Missense-Variant-Pathogenicity
Failure analysis of missense variant pathogenicity predictors using Humsavar/dbNSFP annotations, benchmarking SIFT, PolyPhen-2, CADD, REVEL, logistic regression, and random forest, with AlphaFold-based structural follow-up.
